# Datos geográficos

GeoJSON generados con `make geo` a partir de OpenStreetMap (los usa el tablero sin
conexión). Diccionario de datos y método: [docs/DATOS.md](../../docs/DATOS.md#geo-data-assetsgeo-committed).
